# Contributing to ClaudeCut

Thank you for your interest in contributing to ClaudeCut!

## Guidelines
1. **Fork the Repo:** Create a branch for your bugfix or feature.
2. **Write Unit Tests:** Ensure all tests pass with `python -m unittest tests/run_tests.py`.
3. **Open a Pull Request:** Describe the optimization, bug fix, or improvement clearly.
4. **License Agreement:** By submitting a pull request, you agree that your contributions are licensed under the project's source-available terms.
