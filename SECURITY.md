# Security Policy

## Reporting a Vulnerability

We take security and API key privacy extremely seriously. 

ClaudeCut operates entirely on your local machine / private infrastructure. **No API keys or prompt texts are ever sent to third parties**—requests are routed exclusively between your client and Anthropic's official HTTPS endpoints.

If you discover a security vulnerability, please do NOT open a public issue. Instead, send a private security report to the repository maintainer.
